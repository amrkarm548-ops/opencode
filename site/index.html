ابنِ أفكارك بذكاء،
دون مغادرة الطرفية.

OpenCode هو وكيل برمجة بالذكاء الاصطناعي مفتوح المصدر. يقرأ مشروعك، يخطط للتغييرات، ويكتب الكود وينفّذ الأوامر — من سطر الأوامر أو من تطبيق سطح المكتب.

ابدأ التثبيت ←تصفّح المستودعتطبيق سطح المكتب
~/my-project — zsh
# التثبيت السريع على macOS / Linux
$ curl -fsSL https://opencode.ai/v2/install | bash

# أو عبر مدير الحزم
$ npm i -g @opencode/cli@latest

# ثم شغّله داخل مجلد مشروعك
$ cd my-project && opencode
build

وكيل البناء

الوكيل الافتراضي بصلاحيات كاملة: يعدّل الملفات، يشغّل الاختبارات، ويصلح الأخطاء داخل مشروعك.

plan

وكيل التخطيط

وكيل للقراءة فقط لتحليل الكود واستكشاف المستودعات قبل كتابة أي تغيير. بدّل بينهما بـ Tab.

@general

المهام المعقّدة

وكيل فرعي للبحث متعدد الخطوات، مع دعم الإضافات والأدوات المخصّصة حسب سير عملك.

terminal

واجهة طرفية سريعة

واجهة TUI خفيفة تعمل في أي طرفية حديثة، مع دعم السمات واختصارات لوحة المفاتيح.

desktop

تطبيق سطح المكتب

نسخة بيتا لأنظمة macOS و Windows و Linux لمن يفضّل تجربة رسومية كاملة.

config

قابل للتخصيص

اختر مزوّد النموذج، اضبط الصلاحيات، وأضف تعليمات مشروعك في ملف إعدادات واحد.
